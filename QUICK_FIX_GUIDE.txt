┌──────────────────────────────────────────────────────────────────────────────┐
│ PROBLEM: App hangs for 15 seconds during launch                             │
└──────────────────────────────────────────────────────────────────────────────┘

  WHY? 
  The app waits for cloud requirements to be fetched from the backend API.
  In restricted networks, this times out after 15 seconds with retries.

  WHERE?
  File: codex-rs/core/src/config_loader/mod.rs
  Line: 113

┌──────────────────────────────────────────────────────────────────────────────┐
│ SOLUTION: Add 2-second timeout to cloud requirements fetch                  │
└──────────────────────────────────────────────────────────────────────────────┘

  WHAT CHANGES?
  ┌─────────────────────────────────────────────────────────────────────────┐
  │ BEFORE (blocks for 15s):                                                │
  │                                                                          │
  │   if let Some(requirements) = cloud_requirements.get().await {          │
  │       config_requirements_toml                                           │
  │           .merge_unset_fields(RequirementSource::CloudRequirements,     │
  │                               requirements);                             │
  │   }                                                                      │
  └─────────────────────────────────────────────────────────────────────────┘
                                    ↓
  ┌─────────────────────────────────────────────────────────────────────────┐
  │ AFTER (timeout after 2s):                                                │
  │                                                                          │
  │   match tokio::time::timeout(                                            │
  │       std::time::Duration::from_secs(2),                                 │
  │       cloud_requirements.get()                                           │
  │   ).await {                                                              │
  │       Ok(Some(requirements)) => {                                        │
  │           config_requirements_toml                                       │
  │               .merge_unset_fields(RequirementSource::CloudRequirements, │
  │                                   requirements);                         │
  │       }                                                                  │
  │       Ok(None) => { /* No requirements */ }                              │
  │       Err(_) => { /* Timeout - continue */ }                             │
  │   }                                                                      │
  └─────────────────────────────────────────────────────────────────────────┘
